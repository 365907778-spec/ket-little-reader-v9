# 小小认读家 · KET Reading Garden V9.2

这是以完整 V8 项目为基础整合的 V9.2 版本。

- 首页支持按学习日自由选择 Sentence 03–07（单选或多选）并存储在原有备份中。
- 三张首页学习卡片直接进入当天课程词表：认读新词、听音辨词、看中文拼英文。
- 当天任务02“认读纠正”会显示三项独立进度，全部完成后才算整个任务完成。
- 当天任务05“英语输出”改为浏览器英语语音识别与**基础句法/词汇规则检查**。此功能不是完整AI英语评分，不提供发音评分；复杂表达可能需要家长复核。
- 旧题库、教材音频、家长管理及本机/可选云同步数据结构保持兼容。

完整说明见 `V9.1-更新说明.md` 和 `V9.2-更新说明.md`。

部署前请先在家长空间导出 JSON 备份；更新线上 V9 时建议先在独立预览分支验证。**切勿覆盖 V8 原版仓库。**
