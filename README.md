# 小小认读家 · KET Reading Garden V9.0

## 这次是真实 V8 源码整合版

基础：用户收藏文件中的 `KET_V8_website.zip`。**这次不再通过 iframe 嵌入 V8，而是以原版 V8 源码作为网页运行核心**。

### 已完成

- 首页按照选中的清晰 Minecraft 方块花园视觉重新排版：顶部导航、角色、连续学习、本日进度、四张学习卡、数据、勋章展示和学习记录。
- 原版功能和题库保留：今日学习（含 6 项完整训练）、认读词卡、认词与默写、互动练习题库、复习小站、30 天成长、家长空间。
- `data.js`、`core.js`、`question-bank.js`、`cloud.js` 完全原样保留，所有五段教材完整原音及音频切片保持原样。
- 原版答题记录、错题记录、间隔复习、家长导入/导出备份及可选云同步逻辑未重写。
- 首页数据显示原版浏览器存档中的真实统计，不伪造连续学习天数或成绩。
- 在「看中文拼英文」和「句子默写」已有答题区域，额外加了可选触控/鼠标英文手写板；手写板**只供自己练习**，仍需输入原版答题框才能自动判分。不会把手写轨迹误作为评分、录音或成绩。
- 手机、平板及电脑均可使用。原版 30 天完整计划可在首页底部「展开原版完整训练计划」查看。

### 保持不变的内容

`data.js`、`core.js`、`question-bank.js`、`cloud.js`、`audio/` 及原有样式底层均未修改。`app.js` 只调整了首页渲染层，其他训练、判断、保存及云同步函数保持原样。`index.html` 改布局并引用额外视觉和手写板脚本；`sw.js` 更新缓存清单且使用独立缓存名，不清除 V8 的缓存。

### 使用及部署（推荐新仓库，不覆盖 V8）

1. 先在原版 V8 「家长空间」选择「导出学习备份」，妥善保管 JSON 文件。
2. 在 GitHub 新建公开仓库，例如 `ket-little-reader-v9`。
3. 解压本压缩包，将**所有内容**（包括隐藏的 `.github/` 目录以及 `audio/` 等）上传至新仓库根目录。
4. 进入 GitHub 仓库 **Settings → Pages → Build and deployment → Source：GitHub Actions**。推送到 `main` 分支后会自动部署。
5. 在部署出来的新网址中逐项测试：认读、原音、默写、题库、复习、报告、备份导入导出以及手机端操作。
6. 验证成功之前，**不要删除或覆盖原 V8 网站**。

如果新仓库位于同一 `365907778-spec.github.io` 域名下，且使用同一浏览器用户资料，V8 和 V9 会读取同一 `localStorage` 键 `ket-reading-garden-v1`；但不同域名、浏览器、设备不会自动共享本机存档，需根据实际登录的云同步配置或使用备份导入。上线前仍强烈建议先导出备份。

### 版本关系和限制

- 这份 V9 已真实内置 V8 核心，而不是此前的嵌入式演示版。
- 新首页使用方块花园风格，学习内页采用相同清新主题和更易点按的控件；复杂内页仍保持原 V8 功能布局，避免重写行为造成不兼容。
- 首页「听音辨词」和「拼写挑战」将进入原版「认词与默写」训练中心，需在那里选择具体训练模式。没有新增一个改变原评测流程的新测试系统。
- 手写板不会识别图片里的英文字母，无法单凭笔迹自动评分（需要原版输入框提交）。
- 静态检查已完成，运行环境浏览器访问 localhost/file:// 受到限制，本次未完成完整的真实设备点击与音频回归测试。正式替换 V8 前需要在实际浏览器逐项验证。

### 目录

- `index.html`：入口（V9 顶部视觉 + 原版挂载结构）
- `v9-theme.css`：V9 专用视觉层
- `v9-handwriting.js`：独立手写板增强，不修改原版记录
- `app.js`：原版全部页面路由、学习与记录逻辑 + 新首页渲染器
- `core.js`、`data.js`、`question-bank.js`、`cloud.js`：保持 V8 原版
- `audio/`：全部原版教材音频及切片
- `sw.js`、`manifest.webmanifest`：离线 PWA
- `assets/`：Minecraft 风格配图素材
- `.github/workflows/deploy.yml`：可选 GitHub Pages 自动部署
